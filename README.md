# Flat Plate Convection PINN

Heat transfer final project baseline:

`Physics-Informed Neural Network for Laminar Forced Convection over an Isothermal Flat Plate`

The project will start from a simple Python implementation and gradually build toward predicting the thermal boundary layer and local Nusselt number over an isothermal flat plate.

See `BASELINE.md` for the saved project direction and governing equations.

## Run

```bash
python3 main.py
```
